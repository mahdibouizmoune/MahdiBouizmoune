# Mahdi B. Portfolio

Personal portfolio for El Mahdi Bouizmoune: digital marketing, paid media, CRM automation, and AI content systems.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/.

## Build

```bash
npm run build
```

The site is built with React, TypeScript, Vinext, and Vite. The repository intentionally excludes private source PDFs and environment files.
